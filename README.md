# MHH Jumpstart

Gives the player OP items, equipment, and armor at game start.

Requires [MHH_Prototype_Equipment](https://mods.factorio.com/mod/MHH_Prototype_Equipment) for the item prototypes.

Features:
- Equips prototype armor (Overpowered/Cheaty) or tier-2 armor (Advanced) or vanilla power armor (Balanced) with equipment grid
- Fills the grid with batteries, reactors, shields, exoskeletons, lasers, roboports, night vision, solar panels, belt immunity
- Gives construction and logistic robots, roboports, and spare equipment in inventory
- Configurable armor choice via startup setting
- Detects re-entry (mod updates) and skips already-equipped players
