# MHH Jumpstart

Gives the player OP items, equipment, and armor at game start.

Requires [MHH_RR_Items](https://mods.factorio.com/mod/MHH_RR_Items) for the item prototypes.

Features:
- Equips rr-power-armor (or se-thruster-suit-4 with Space Exploration) with full equipment grid
- Fills the grid with batteries, reactors, shields, exoskeletons, lasers, roboports, night vision, solar panels, belt immunity
- Gives construction and logistic robots, roboports, science packs, and spare equipment in inventory
- Configurable armor choice via startup setting
- Detects re-entry (mod updates) and skips already-equipped players
